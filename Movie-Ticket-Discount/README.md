# Movie Ticket Discount Calculator

## Description
A C program that calculates the best available movie ticket discount based on a customer's age and VIP membership.

## Features
- Child discount for customers under 13
- Senior discount for customers aged 65 and older
- VIP member discount
- Applies only the highest eligible discount
- Displays the original ticket price, discount applied, and final price

## Concepts Practiced
- Variables and data types
- User input and output
- Conditional statements
- String handling
- Character input
- Basic arithmetic
